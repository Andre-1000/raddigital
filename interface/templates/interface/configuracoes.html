Exclusivo do Administrador. Escolha um campo para ver e alterar se ele está habilitado e se é obrigatório.

Um campo desabilitado some para todos os usuários, inclusive Administradores — obrigatoriedade não tem efeito nesse caso. Alguns campos têm regra condicional própria (ex.: N° Falha só é exigido quando o Tipo de Manutenção é Falha); marcar como obrigatório aqui faz o campo ser sempre exigido, independente da condição original.
